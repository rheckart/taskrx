# Issue tracker: Forgejo (MCP)

Issues and PRDs for this repo live on a self-hosted Forgejo instance at `https://git.heckart.me`,
managed through the `forgejo-mcp` server. This server exposes Forgejo API operations as MCP tools.

## Server

- **URL**: `https://git.heckart.me`
- **Transport**: HTTP (streamable)
- **Forgejo version**: 15.0.5+gitea-1.22.0
- **MCP server version**: 2.30.2

## When a skill says "publish to the issue tracker"

Use the Forgejo MCP tools to create an issue on the repo.

## When a skill says "fetch the relevant ticket"

Use the Forgejo MCP tools to read the issue by number, including comments and labels.

## Pull requests as a triage surface

Not configured for this repo.
